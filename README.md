# אילן היוחסין של משפחת יהודה (The Yehuda Family Tree)

אפליקציה מתקדמת, אינטראקטיבית ורספונסיבית לניהול, תצוגה, ייבוא, ייצוא והדפסה של אילן יוחסין משפחתי רב-דורי.

---

## 🌳 מאפייני המערכת
* **קנבס אינטראקטיבי:** תמיכה מלאה בגרירה (Pan) וזום מדויק (גלגלת עכבר וצביטה במסכי מגע) ללא סטיית עצמים.
* **תמיכה בריבוי בני/בנות זוג:** קישור גמיש של מספר בני זוג לאותו אדם, כולל קישור מדויק של הורה-משותף (Coparent) וילדים לכל שותפות.
* **3 מצבי תצוגה:**
  1. תצוגה מפורטת לאורך (כרטיסים עשירים עם תמונות, תאריכי לידה/פטירה, דורות ופעולות מהירות).
  2. תצוגה מקוצרת לאורך (קומפקטית, שמות ותאריכים).
  3. תצוגה מקוצרת לרוחב (מימין לשמאל RTL).
* **ייבוא קבצים חכם (Universal JSON & SVG):**
  * ביטול תלות בשירותי צד שלישי – טעינה ישירה של קבצי `.json` מכל מבנה (רשימת אנשים עם בני זוג, צאצאים והורים, או גיבוי מלא) וכן קבצי `.svg`.
  * אפשרות להדבקת טקסט JSON ישירות.
  * מסך אימות ובדיקה המאפשר עריכה ובחירה בין "החלפת העץ" ל"מיזוג עם העץ הקיים".
* **ייצוא מקיף:**
  * **JSON:** גיבוי מלא או רשימת אנשים וקשרים מובנית וקריאה, עם העתקה ללוח והורדה בקליק.
  * **PNG:** תמונה מלאה של כל העץ (1x, 2x, 3x) ברזולוציה גבוהה.
  * **PDF A4:** עמוד בודד בהתאמה מלאה או פוסטר רב-עמודי המחולק אוטומטית לעמודי A4.

## 💾 איפה נשמר בסיס הנתונים?
המערכת פועלת במודל היברידי גמיש:

1. **בעבודה עם שרת (Node.js / Express):**
   * הקובץ הפיזי נשמר בנתיב: `data/family-tree.json` בשרת.
   * נקודת ה-API המספקת את הנתונים: `GET /api/tree` ושמירה ב-`POST /api/tree`.
2. **בדפדפן (לקוח):**
   * נשמר במקביל ב-`localStorage` של הדפדפן (`family_tree_yehuda_v1`), המאפשר פעולה מיידית ומהירה גם בתנאי רשת חלשים וסנכרון דו-כיווני מול השרת.
3. **באחסון סטטי (GitHub Pages):**
   * עץ המשפחה הבסיסי מוטמע ישירות בקוד המקור (`src/data/initialFamilyTree.ts`), כך שעם פתיחת האתר הוא מוצג מיד.
   * כל עריכה נשמרת ב-`localStorage`, וניתן תמיד לייצא ולייבא קבצי JSON מלאים.

## 🌐 פריסה אוטומטית ל-GitHub Pages
הפרויקט מוגדר עם קובץ אוטומציה של **GitHub Actions** (`.github/workflows/deploy.yml`):
1. דחוף את הפרויקט ל-GitHub (ענף `main`).
2. בהגדרות המאגר ב-GitHub: **Settings > Pages**.
3. תחת **Build and deployment > Source**, בחר: **GitHub Actions**.
4. המערכת תבנה ותפרסם את האתר אוטומטית לכתובת:
   `https://<your-username>.github.io/<repo-name>/`
